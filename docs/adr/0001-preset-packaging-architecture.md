# 0001. 基于 package.json 依赖聚合的极致预设架构

- 状态: 已接受 (Accepted)
- 日期: 2026-03-30
- 决策人: 鲸鱼娘开发助手 & 主人

## 背景与上下文 (Context)
用户明确要求“极致的简单，直接安装一个预设就等于安装了全部扩展”，同时不希望编写额外的 JS 胶水代码或运行手动同步脚本。

## 架构决策 (Decision)
1. **依赖委托机制**：
   在预设的 `package.json` 的 `dependencies` 中，直接声明全部 22 个第三方扩展的 npm 包与 git 仓库远程依赖。
2. **资源路径显式暴露**：
   利用 Pi 官方规范，在 `package.json` 的 `pi` 字段（`extensions`, `skills`, `themes`）中直接暴露依赖项中各模块的入口路径及本地 `skills/*`。
3. **零 JS 代码**：
   整个工程不包含任何自定义的 CLI 脚本或编译代码，纯粹依托 npm 包依赖树与 Pi 原生资源发现协议。

## 收益与结果 (Consequences)
- **终极极简体验**：安装预设包后即可全量获得所有扩展和技能。
- **完全免维护**：升级扩展只需在 `package.json` 的 `dependencies` 中调整版本号或 git ref。
