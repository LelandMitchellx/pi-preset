# Pi Preset 🚀

> **先把规矩先立住，vibe才不烧心**：基于 Pi 原生包规范打造的开箱即用终极预设。通过 `package.json` 将第三方远程扩展声明为依赖，免去逐个配置的繁琐流程，安装一个预设即拥有全部生产力工具！

---

## ⚡ 设计理念：为什么能“装一个预设 = 拥有全部扩展”？

1. **依赖全托管**：在 `package.json` 的 `dependencies` 中收录第三方远程扩展的 npm 包与 GitHub 远程仓库，版本集中管控。
2. **原生资源挂载**：在 `pi.extensions`、`pi.skills` 与 `pi.themes` 字段直接暴露各依赖入口，并随包内置本地工程技能。
3. **零胶水代码**：无多余的辅助脚本或配置同步文件，完全依靠 npm 依赖树与 Pi 官方原生扩展发现机制驱动。

---

## 🚀 极速安装方式

在任何环境（宿主或 WSL）中，仅需一行命令即可将本预设接入 Pi：

```bash
# 方式 A：本地工程一键安装
cd pi-preset
npm install
pi install .

# 方式 B：从远程 Git 仓库直接安装
pi install git:github.com/<your-username>/pi-preset
```

## 📦 全量扩展与技能矩阵 (WSL 8大架构维度对齐)
